## 1. 왜 이렇게 만들었나

이 저장소의 원칙은 `docs/00` §8 — **"검증한 척"을 만들지 않는다** 입니다.
`javascript-면접/README.md` 에는 지금까지 "**이 저장소에는 자바스크립트 실행 검증 모듈이 없다**"고
적혀 있었습니다. 그 문장을 지우기 위해 만든 모듈입니다.

- **의존이 0 입니다.** Node 22 내장 러너(`node --test`)와 `node:assert` 만 씁니다.
  `npm install` 이 없으니 공급망도, 잠금 파일도 없습니다.
- **브라우저가 필요한 문항은 여기 없습니다** → 렌더링(Q26)·DOM 이벤트(Q23)·CORS 의 브라우저 쪽(Q30)·
  Web Worker(Q43)는 Node 에서 판정할 수 없습니다. 언어·런타임(Node) 범위만 다룹니다.
- **시간을 재지 않습니다.** 병행/직렬은 "동시에 떠 있던 최대 개수"로, 지연 평가는 "호출 횟수"로,
  백프레셔는 "버퍼에 쌓인 개수"로 잽니다. 전부 장비와 무관하게 결정적입니다.
  디바운스·스로틀은 `node:test` 의 **가짜 타이머**로 시계를 돌려서 단정합니다.

## 2. `fact` / `observe` / `lesson`

[`lessons/lesson.js`](lessons/lesson.js) 에 도구가 세 개 있습니다. `java-tutorial` 의 `Lesson.java` 와 같습니다.

| 도구 | 뜻 | 판정에 쓰이나 |
|---|---|---|
| `fact(라벨, 값)` | 확인된 값을 콘솔에 남긴다 | 아니오 (기록용) |
| `observe(라벨, 값)` | **환경에 좌우되는 값**. 단정하지 않는다 | 아니오 |
| `lesson(문장)` | 레슨의 결론 한 줄 | 아니오 |

판정은 오직 `assert` 가 합니다. **테스트가 초록이라고 해서 `observe` 로 찍힌 줄까지 증명된 것은 아닙니다.**
현재 `observe` 는 **5곳**입니다 — 3-6(메인에서의 `setTimeout` vs `setImmediate` 순서), 3-7(I/O 완료 순서),
7-4(GC 뒤 `WeakRef.deref()`), 7-5(`FinalizationRegistry` 콜백 도착), 8-6(워커가 도는 동안 메인 타이머 횟수).

예를 들어 7-4 는 이렇게 나옵니다.

```
   ~ 강한 참조를 끊고 gc() 뒤 WeakRef.deref()           = undefined (회수됨)   (환경 의존 — 단정하지 않음)
```

단정한 것은 **`Map` 이 잡고 있는 한 절대 회수되지 않는다**뿐입니다. "끊으면 회수된다"는
`--expose-gc` 로 강제해도 사양이 약속하지 않으므로 단정하지 않았습니다.

## 5. 정직한 고지

- **50문항 중 24문항이 레슨에 걸렸습니다**(Q1~12·14~20·32~34·36·38). 나머지는 브라우저가 필요하거나
  (Q23·Q25~31·Q40~43), 설계·경험 문항(Q35·Q37·Q39·Q44~50)이거나, TypeScript(Q21·22)입니다.
  커버리지가 아니라 **판정 가능성**으로 골랐습니다.
- **`observe` 로 찍힌 5줄은 검증되지 않았습니다.** 특히 7-4·7-5 의 GC 관측은 `--expose-gc` 로 강제해도
  "회수된다"를 보장하지 않습니다. 단정한 것은 그 반대(강한 참조가 있으면 회수되지 않는다)뿐입니다.
- **8-6 의 "워커가 도는 동안 타이머가 0회가 아니다"는 타이밍에 기댑니다.** 워커 기동만으로도 수십 ms 가
  걸려 사실상 항상 참이지만, 엄밀히는 `fib(30)` 이 타이머 한 틱보다 오래 걸린다는 가정 위에 있습니다.
  횟수 자체는 `observe` 했습니다.
- **Node 22.22.2 에서만 돌렸습니다.** `t.mock.timers`(7-1·7-2)·`toSorted`(5-4)·`AbortSignal.any`(7-6)·
  `structuredClone`(5-3) 은 Node 20 미만에서 없거나 다릅니다. `package.json` 에 `engines: node >= 22` 로 적어 뒀습니다.
- **성능 수치는 하나도 없습니다.** "빠르다/느리다"는 이 모듈이 다루지 않습니다 — `docs/02` §1-2 의 규칙대로
  시간 측정이 필요한 주장은 여기 넣지 않았습니다.
