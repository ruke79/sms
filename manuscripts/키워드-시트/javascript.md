| 9 🔴 | `async`/`await` 에러 | `try`/`catch` · **`await` 빠뜨린 Promise 는 안 잡힘 → 프로세스 크래시** · `unhandledRejection` ▶4-5·4-9 |
| 10 🔴 | 비동기 병행 | `for` 안 `await` = 직렬 · 먼저 만들어 `Promise.all` · **동시 실행 수 제한**(상대 서버 보호) ▶4-7·4-8 |
| 11 | 얕은/깊은 복사 | 스프레드는 한 겹 · `structuredClone` · **JSON 왕복은 `Date`·`undefined`·순환에서 깨짐** ▶5-2·5-3 |
| 12 | `null` vs `undefined` | 의도적 빈 값 vs 아직 없음 · `?.` · **`??` 는 `0`·`""` 을 살림**(`\|\|` 버그) ▶5-6 |
| 13 | `map`/`filter`/`reduce` | 변환/걸러내기/집약 · 원본 불변 · `reduce` 읽기 어려우면 루프 · **`forEach` 는 못 빠져나옴** |
| 14 | 파괴/비파괴 메서드 | `push·splice·sort·reverse` 파괴 · **`sort` 기본은 문자열 비교** · `toSorted` ▶5-4·5-5 |
| 15 | `Map` vs 객체 | 비문자열 키·동적 증감 → `Map` · **객체 사전은 `__proto__`·`constructor` 키 사고** ▶2-4 |
| 16 | CJS vs ESM | 동기·런타임 해석 vs 정적 분석 → 트리 셰이킹·톱레벨 `await` · **ESM 은 라이브 바인딩, CJS 는 값 복사** ▶6-5·6-6 |
| 17 | 제너레이터·이터레이터 | `Symbol.iterator` · `function*`/`yield` · **`for await` 로 스트림** · `break` 가 `finally` 실행 ▶6-1~6-4 |
| 18 | 디바운스 vs 스로틀 | 마지막 뒤 한 번 vs 간격당 최대 한 번 · 자동완성/스크롤 · **파기 시 타이머 정리** ▶7-1·7-2 |
| 19 🔴 | 메모리 누수 | **리스너·타이머 해제 누락**이 최다 · 전역 캐시 · 클로저 · 힙 스냅샷 **2점 차분** ▶7-3·7-4 |
| 20 | 숫자 정밀도 | IEEE 754 · 금액은 정수 최소 단위/`BigInt` · **64비트 ID 는 문자열로 받기** ▶5-7 |
| 21 | TypeScript 이유 | 쓰는 도중 에러 발견 · 리팩터링 안전 · **컴파일 후 타입 사라짐 → 경계에서 스키마 검증** |
| 22 | `any` vs `unknown` | 검사 포기 vs 좁히기 강제 · **입력 수신부는 `unknown`** · `any` 는 lint 로 검출 |
| 23 | 버블링·위임 | 대상 → 조상 전파 · 부모에 하나 + `event.target` · **동적 요소에 자동 적용** · 리스너 수 비례 안 함 |
| 24 🔴 | `localStorage`·`sessionStorage`·Cookie | 영속/탭/자동 전송 · **인증 토큰을 `localStorage` 에 두면 XSS 로 탈취** · `HttpOnly`·`Secure`·`SameSite` |
| 25 🔴 | XSS 방어 | **출력 시 이스케이프**(프레임워크 기본 풀지 않기) · `innerHTML` 금지 · CSP · `HttpOnly` |
