# Kubernetes Q1~Q50 키워드 시트
## 50문항 · 한 문서 · 매일 훑기 / 면접 직전용

> **사용법**: 키워드만 보고 일본어로 말할 수 있으면 실전 가능선. 원문은 [`../kubernetes-면접/`](../kubernetes-면접/README.md).
> **굵은 글씨** = 다른 지원자와 차이를 만드는 차별화 포인트. 시간이 없어도 이것만은 반드시.
> 🔴 = [`필수-키노트`](../kubernetes-면접/필수-키노트.md) 의 **S급 10문항**(반드시 나온다).
>
> ⚠️ 이 세트에는 실행 근거(`✅` 케이스 id)가 **없다.** 클러스터를 띄우는 검증 모듈이 이 저장소에 없다. **수치를 말하지 않는다.**

# Part 1. 오브젝트·네트워크·리소스 (Q1~25)

| Q | 질문 | 키워드 |
|---|---|---|
| 1 | K8s 가 해결하는 것 | "어디서 몇 개"를 선언적으로 · 컨트롤러가 현재 → 원하는 상태로 수렴 · **절차가 아니라 상태를 적는다** |
| 2 | 컨트롤 플레인 vs 데이터 플레인 | API 서버·etcd·스케줄러·컨트롤러 매니저 / kubelet·kube-proxy·런타임 · **API 서버가 유일한 입구** · etcd 백업 |
| 3 | Pod 이 최소 단위인 이유 | 네트워크·스토리지 공유하는 컨테이너 묶음 · **본체와 생사를 같이하는 보조 프로세스** · 독립 확장은 다른 Pod |
| 4 | Deployment·ReplicaSet·Pod | 3층인 이유 = **갱신 시 신·구 ReplicaSet 병행** · 롤백은 이전 RS 로 · Pod 직접 만들면 아무도 안 살림 |
| 5 | StatefulSet vs Deployment | 안정적 이름·전용 볼륨·순서 보장 · **개체 식별이 의미 있는 것**(DB·브로커) · 스테이트리스에 쓰면 느려지기만 · 볼륨은 남음 |
| 6 | DaemonSet | 모든 노드에 하나 · 로그·모니터링 에이전트·CNI · 항상 리소스 소비 → **가볍게 + 리소스 제한** |
| 7 🔴 | Service | **안정적인 목적지** · Pod IP 는 바뀜 · 셀렉터 → 라벨 매칭 · kube-proxy 규칙 · 클러스터 DNS |
| 8 | Service 타입 | ClusterIP/NodePort/LoadBalancer · 외부 공개는 **Ingress 로 집약**(LB 개수만큼 과금) · 헤드리스 + StatefulSet |
| 9 | Ingress | 호스트·경로 분배 · TLS 종료 · **사양일 뿐, 일하는 건 컨트롤러** → 기능이 컨트롤러 의존 · Gateway API |
| 10 | 요청이 Pod 에 닿는 경로 | 외부 LB → Ingress 컨트롤러 → Service → kube-proxy → Pod · 내부는 DNS → ClusterIP · **어디서 끊겼는지가 조사 절차** |
| 11 🔴 | liveness vs readiness | 죽었으면 재시작 / 준비 안 됐으면 트래픽 차단 · **liveness 에 무거운 의존 검사 → DB 잠깐 느린 것으로 재시작 루프** |
| 12 | startupProbe | 기동 느린 앱 · 없으면 기동 중 liveness 실패 반복 · JVM 워밍업 · **기동 유예와 가동 중 판정 분리** |
| 13 🔴 | requests vs limits | 스케줄링 확보량 vs 상한 · **CPU 초과 = 스로틀, 메모리 초과 = OOMKilled** · requests 없으면 스케줄러가 판단 못 함 |
| 14 🔴 | limits 와 JVM | JVM 이 컨테이너 제한 보고 자기 구성 · **CPU 1 이면 Serial GC** · 메모리 비율로 힙 · **힙 밖(메타스페이스·스택·네이티브) → limit 은 힙보다 충분히 크게** |
| 15 | QoS 클래스 | Guaranteed/Burstable/BestEffort · **메모리 부족 시 BestEffort 부터 축출** · 중요 워크로드는 Guaranteed |
| 16 | 스케줄링 제어 | 셀렉터·어피니티 "어디에" / taint·toleration "누구를" · **안티 어피니티로 노드·존 분산** · GPU 노드 taint |
| 17 | ConfigMap vs Secret | 설정 / 기밀 · **Secret 은 base64 지 암호화가 아님** → etcd 암호화 + RBAC · 외부 비밀 관리 · 환경변수는 프로세스 목록·로그로 샘 |
| 18 | 설정 변경 반영 | 환경변수 → 재시작 필요 · 볼륨 → 파일은 갱신되지만 **앱이 다시 안 읽으면 무의미** · 설정 해시를 어노테이션에 → 자동 롤링 |
| 19 🔴 | 롤링 업데이트 | 새 RS 늘리고 옛 RS 줄임 · `maxSurge`/`maxUnavailable` · **readiness 통과까지 트래픽 안 옴 → readiness 가 전제** |
| 20 | 배포 전략 선택 | 기본 롤링 · 위험 큰 변경은 카나리 + 지표 · DB 스키마는 신·구 동시 가동 형태로 · **되돌릴 수 있게 하는 게 먼저** |
| 21 🔴 | Pod 안전 종료 | Service 에서 빼기와 SIGTERM 이 **병행** → 빠지기 전 죽으면 요청 실패 · SIGTERM 후 잠시 대기 · **`preStop` 몇 초** · grace period > 처리 시간 |
| 22 | HPA | 지표로 Pod 증감 · **requests 없으면 CPU 사용률 계산 불가** · 병목이 DB/외부면 늘려도 무의미 · 진동 방지 |
| 23 | Job / CronJob | 1회 / 정기 · 재시도·병렬도 · `concurrencyPolicy` · **그래도 두 번 돌 수 있음 → 멱등** · 이력 보존 수 |
| 24 | 영속 볼륨 | PVC → StorageClass · **블록 스토리지는 한 노드만** · 공유는 파일 스토리지 · 삭제 정책에 따라 PVC 삭제 = 데이터 소실 |
| 25 | namespace 목적 | 이름 충돌·권한·할당 단위 · RBAC/Quota/NetworkPolicy · **강한 격리 아님**(같은 노드) · 개발/운영을 ns 로 나누지 않기 |

# Part 2. 운영·트러블슈팅·보안 (Q26~50)

| Q | 질문 | 키워드 |
|---|---|---|
| 26 🔴 | Pod 이 안 뜰 때 | **상태마다 원인 위치가 다름** · `Pending`(스케줄 불가) / `ImagePullBackOff` / `CrashLoopBackOff` · `describe` 이벤트 · `--previous` |
| 27 🔴 | OOMKilled | **부족인가 누수인가**(우상향이면 누수) · limit 상향 · JVM 힙 밖 잊지 않기 · **limit 은 힙보다 충분히 크게** |
| 28 🔴 | 서비스에 연결 안 될 때 | 경로 순서대로 · **`Endpoints` 비었나** → 라벨 불일치 or readiness 미통과 · 포트 → DNS → NetworkPolicy · Pod 안에서 직접 호출 |
| 29 | NetworkPolicy | 기본 전부 통신 가능 · 적용하면 허용한 것만 · 전면 거부 후 열기 · **CNI 미대응이면 아무 일도 안 일어남** → 실제로 막혔는지 확인 |
| 30 | RBAC | Role/RoleBinding · 네임스페이스 넘으면 ClusterRole · 최소 권한 · **`cluster-admin` 뿌리지 않기** · Pod 서비스 어카운트 권한 좁히기 |
| 31 | 컨테이너 보안 | root 금지 · 읽기 전용 FS · 권한 떨구기 · `privileged` 금지 · **최소 베이스 이미지 + 취약점 스캔 CI** · 디버그는 임시 컨테이너 |
| 32 | 이미지 태그 운용 | **`latest` 금지** · 커밋 해시·버전·다이제스트 고정 · `imagePullPolicy` · 같은 태그 바꿔치기 = 노드마다 다른 이미지 |
| 33 | 노드가 죽으면 | NotReady → 축출 → 다른 노드에 재생성 · **즉시가 아님**(판정 유예) · 복제본 노드 분산 전제 · StatefulSet 은 볼륨 사정 |
| 34 | 노드 교체 | `cordon` → `drain` · **PodDisruptionBudget 으로 동시 정지 수 제한** · 없으면 복제본 한꺼번에 축출 |
| 35 | 리소스 압박 시 | 메모리 → 축출(QoS 순) · **CPU → 스로틀("느리지만 안 죽음")** · 지연 조사 시 CPU 스로틀 지표 확인 |
| 36 | 로그 수집 | 표준 출력 → 노드 에이전트 → 외부 · 파일 쓰기는 로테이션·수집 직접 · **Pod 사라지면 로그도 사라짐** · 구조화 + 요청 ID |
| 37 | 모니터링 | 요청·에러·지연 / 리소스·**재시작 횟수**·Pending 수 · 재시작 조용히 늘면 liveness·메모리 의심 · 백분위수 |
| 38 | 매니페스트 관리 | Git · Kustomize/Helm · `kubectl edit` 은 다음 배포에 사라짐 · **GitOps = 클러스터 상태가 Git 과 일치함을 도구가 보장** |
| 39 | Helm vs Kustomize | 템플릿+값 패키지 / 베이스+차분 · 외부 배포·복잡 분기 → Helm · 환경별 소폭 차이 → Kustomize · **템플릿이 YAML 을 못 읽게 하면 분기점** |
| 40 | Operator / CRD | API 확장 + 운영 절차 컨트롤러화 · DB 백업·페일오버 · **직접 만들면 그것을 유지보수** → 기존 Operator 먼저 |
| 41 | 서비스 메시 | mTLS·재시도·서킷·가시화를 코드 무수정으로 · **사이드카만큼 리소스·지연 증가** · 서비스 몇 개면 라이브러리로 충분 |
| 42 | 사이드카 | 본체와 생사 같이하는 보조 · **본체보다 먼저 죽으면 종료 처리가 통신 못 함** → 네이티브 사이드카(init 상주) |
| 43 | init 컨테이너 | 본체 전 필수 준비 · 권한·도구를 준비 단계에 가둠 · **DB 마이그레이션을 전 Pod 에서 돌리면 경합 → Job 으로** |
| 44 | 멀티테넌트 클러스터 | namespace 는 **강한 격리 아님** · 시끄러운 이웃 · Quota·LimitRange·NetworkPolicy · 정말 필요하면 노드 풀/클러스터 분리 |
| 45 | 클러스터 업그레이드 | 컨트롤 플레인 먼저 · 버전 차이 범위 · **제거된 API 버전 사전 검출**(CI) · 한 대씩 drain + PDB |
| 46 | 비용 최적화 | **실사용량 vs requests 차이**(과도한 requests = 안 쓰는 노드 구매) · 오토스케일 · 스팟은 죽어도 되는 워크로드만 |
| 47 | 배포했는데 반영 안 됨 | 새 Pod 이 떠 있나(readiness·Pending) · **같은 태그 재사용 → 노드 캐시로 옛 이미지** · 환경변수 설정 후 미재시작 |
| 48 | 일부 요청만 느림 | 특정 Pod 에 몰리나 → 노드 혼잡·CPU 스로틀 / 안 몰리면 하류·데이터 · 분산 트레이싱 · **백분위수 + Pod 단위** |
| 49 | K8s 를 넣지 말아야 할 때 | 서비스 적고 운영 인력 한정 · **클러스터 자체 운영 비용 > 이점** · 매니지드 컨테이너/PaaS · "다들 쓰니까" = YAML 유지보수만 남음 |
| 50 🔴 | 장애 시 먼저 할 것 | 영향 범위 + **최근 변경**(대부분 직전 배포·설정) → 필요하면 되돌림 · 복구 > 원인 규명 · 이벤트→상태→리소스→로그 · 즉시 대처와 재발 방지 분리 |

# 🚨 함정 문항 (틀리면 즉시 감점)

| Q | 함정 | 정답 방향 |
|---|---|---|
| 11 | liveness 에 DB 연결 확인 | 재시작 루프. 의존 검사는 readiness |
| 13 | "CPU 도 limit 넘으면 죽는다" | CPU 는 **스로틀**, 메모리만 OOMKilled |
| 14 | 힙 = 컨테이너 limit | 메타스페이스·스택 몫에서 반드시 초과 |
| 17 | "Secret 은 암호화돼 있다" | base64 인코딩일 뿐 |
| 21 | "SIGTERM 오면 바로 종료 처리" | Service 에서 빠지기 **전**일 수 있음 → `preStop` 대기 |
| 25 | 개발/운영을 namespace 로 분리 | 같은 노드 = 강한 격리 아님 |
| 29 | NetworkPolicy 썼으니 막혔다 | CNI 미대응이면 무효 — 실제로 확인 |
| 32 | 같은 태그로 이미지 덮어쓰기 | 노드 캐시 → 노드마다 다른 코드 |
