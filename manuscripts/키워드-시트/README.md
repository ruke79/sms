## 정직한 고지

- **`Q1-Q200.md` 는 사용자가 만들어 준 파일을 그대로 등록한 것이다.** 이 저장소가 문장 단위로 다시 검증하지 않았다.
  🔴 의 기준(A급 60)도 원저자의 것이라 다른 일곱 장과 다르다. 사실관계가 갈리면 [`수정본/`](../수정본/) 이 기준이다.
- **나머지 일곱 장은 각 세트의 한국어 답변에서 이 저장소가 뽑았다.** 키워드는 답변에 **있는 말**만 줄였고,
  답변에 없는 내용을 보태지 않았다. 다만 줄이는 과정은 사람 손이라, 원문과 뉘앙스가 다르게 읽히면 원문이 맞다.
- **✅ 는 근거가 있는 곳에만 붙였다.** Python·Kubernetes 시트에 ✅ 가 하나도 없는 것은 빠뜨린 게 아니라
  **이 저장소가 그쪽을 실행으로 확인하지 못했기 때문**이다(`docs/00` §8). 없는 것을 있는 것처럼 적지 않는다.
- **CI 가 검사하는 것은 번호와 근거 id 뿐이다.** [`scripts/check-keyword-sheets.py`](../../scripts/check-keyword-sheets.py) 가
  원문 Part 파일의 `### Qn.` 과 시트의 `| n |` 을 대조해 **누락·유령 번호**를 잡고, 시트의 ✅ id 가 실제
  `VerificationCase.id()` 에 있는지 본다. **키워드가 답변을 잘 요약했는지는 기계가 못 본다** — 그건 원문 대조가 답이다.

```bash
./scripts/check-keyword-sheets.py   # 8장 전부: 누락 0 · 유령 번호 0 · 허구 근거 id 0
```

## 이렇게 쓴다

**시트는 외우는 문서가 아니라 확인하는 문서다.** 키워드를 보고 일본어 문장이 나오면 그 문항은 됐고, 안 나오면
원문으로 돌아간다. 매일 훑는 것은 시트, 막힐 때 읽는 것은 원문, 전날 보는 것은 함정 표와 📌 목록,
당일 보는 것은 키노트의 **일본어 한 문장**이다. 플래시카드([`../플래시카드/`](../플래시카드/README.md))와 짝으로 쓰면
카드가 "말할 수 있나"를, 시트가 "빠진 문항이 없나"를 맡는다.
