# Part 1. 언어 핵심 (Q1~25)

| Q | 질문 | 키워드 |
|---|---|---|
| 1 | 리스트 vs 튜플 | 가변/불변 · 튜플은 **딕셔너리 키·집합 원소 가능** · "바뀌는 것"과 "고정 묶음"으로 구분 |
| 2 🔴 | 기본 인자에 리스트 | **정의 시점에 한 번만 평가** → 호출 간 공유 · `None` 기본 + 함수 안에서 생성 |
| 3 🔴 | 얕은 복사 vs 깊은 복사 | 한 겹 vs 재귀 · 중첩 구조 얕은 복사 → 원본 오염 · `deepcopy` 는 비쌈 → **애초에 불변 설계** |
| 4 | `is` vs `==` | 동일 객체 vs 값 · **인터닝에 의존 금지** · `is` 는 `None` 판정에만 |
| 5 | 딕셔너리 내부·순서 | 해시 테이블 · O(1) · **3.7 부터 삽입 순서가 언어 사양** (3.6 은 구현 세부) |
| 6 | 딕셔너리 키 조건 | 해시 가능 = 불변 + `__hash__`/`__eq__` 일관 · **`__eq__` 정의하면 `__hash__` 도** |
| 7 | 컴프리헨션이 빠른가 | 대체로 빠름(`append` 해석 생략) · **가독성 우선** · 부수효과 없는 변환에만 |
| 8 🔴 | 제너레이터 장점 | **메모리가 요소 수에 비례하지 않음** · 무한 수열 · 한 번만 순회 |
| 9 | 이터레이터 vs 이터러블 | `__iter__` vs `__next__`(상태) · 리스트는 이터러블이지 이터레이터 아님 · **제너레이터 두 번 못 도는 이유** |
| 10 | 클로저·루프 변수 | 잡는 건 **값이 아니라 변수** → 전부 마지막 값 · 기본 인자로 묶기 / `partial` |
| 11 | 데코레이터 | 함수→함수 · 로깅·재시도·캐시 · **`functools.wraps` 필수**(이름·독스트링 보존) |
| 12 | `*args`/`**kwargs` | 튜플/딕셔너리 · 래퍼에서 통과용 · **공개 API 에서 남발 금지**(시그니처 불명) |
| 13 | 스코프 해결 | **LEGB** · `global`/`nonlocal` · 둘 다 쓰면 **설계 재검토 신호** |
| 14 🔴 | GIL | 한 스레드만 바이트코드 실행 · 참조 카운팅 보호 · **제한은 CPU 바운드 병렬화** · I/O 대기 중 해제 |
| 15 🔴 | 스레드·프로세스·asyncio | I/O 다수 연결 → asyncio · I/O+블로킹 라이브러리 → 스레드 · CPU → 프로세스 · **"기다리나, 계산하나"** |
| 16 🔴 | `async`/`await` | `await` 에서 루프에 양보 · **코루틴 안 블로킹 호출 = 루프 전체 정지** · `run_in_executor` |
| 17 | `else`/`finally` | `else` 는 예외 없을 때만 · `try` 는 최소로 좁히고 **후속은 `else`** · 정리는 `finally`/컨텍스트 매니저 |
| 18 | 컨텍스트 매니저 | 진입/이탈 짝 · 예외 나도 정리 보장 · `contextmanager` · **`finally` 누락 여지 제거** |
| 19 | `__init__` vs `__new__` | 초기화 vs 생성 · `__new__` 는 **불변 타입 상속·싱글턴**에 한정 |
| 20 | MRO | C3 선형화 · `__mro__` · **`super()` 는 부모가 아니라 "MRO 상 다음"** · 협조적 다중 상속 |
| 21 | `@property` | 속성 형태 유지 + 계산·검증 · 나중에 바꿔도 호출부 그대로 · **무거운 처리 금지**(싸다고 오해) |
| 22 | `dataclass`/`NamedTuple`/딕셔너리 | 구조 고정/불변 값 묶음/동적 키 · **딕셔너리를 타입처럼 쓰는 게 최다 실패**(오타·자동완성) |
| 23 | `__slots__` | `__dict__` 제거 · 메모리 절감 · 대량 객체 · **속성 추가 불가를 "의도"로 쓸 자리에만** |
| 24 | 덕 타이핑·ABC·Protocol | 행동 기반 · ABC 는 상속 강제 · **Protocol 은 상속 없이 구조만으로** · 외부 라이브러리에 유리 |
| 25 | 타입 힌트 런타임 | **무시됨** → mypy CI · 가치는 자동완성·리팩터링·**계약이 코드에 적힘** · 런타임 검증은 Pydantic |
